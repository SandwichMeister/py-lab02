# streamstats

Лабораторная работа 2. Потоковый анализатор событий из CSV и JSONL.

Программа читает файлы построчно, проверяет обязательные поля, считает события по уровням
и источникам, находит top-5 источников ошибок, первую и последнюю метку времени и
сохраняет результат в JSON-отчёт.

## Установка

```bash
python -m pip install -e ".[dev]"
```

## Использование

```bash
python -m streamstats analyze INPUT [INPUT ...] --format csv|jsonl --output REPORT.json
python -m streamstats analyze INPUT --format jsonl --skip-invalid
```

- `INPUT` — один или несколько входных файлов одного формата; статистика объединяется.
- `--format` — формат входных файлов: `csv` (с заголовком) или `jsonl`.
- `--output` — файл отчёта. Без него отчёт печатается на экран.
- `--skip-invalid` — пропускать ошибочные строки вместо остановки.

## Ошибочные строки

Без `--skip-invalid` программа останавливается на первой ошибочной строке, выводит файл и
номер строки и завершается с кодом `2`. С `--skip-invalid` строка пропускается с `WARNING`,
а число пропущенных строк записывается в отчёт.
